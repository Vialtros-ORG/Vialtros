# Backend Vialtros

El backend Django expone la API REST y los canales WebSocket usados por el
frontend. Para la instalación completa, sigue el
[README del repositorio](../README.md); para ejecutar el servicio en Compose,
consulta [Docker Compose](../docs/docker-compose.md).

La configuración local se explica en
[Variables de entorno](../docs/variables-entorno.md), y los detalles de imagen,
migraciones y pruebas están en [Docker del backend](../docs/docker-backend.md).
La referencia de endpoints está en [API](../docs/api.md).
